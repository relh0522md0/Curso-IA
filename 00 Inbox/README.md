# 00 Inbox

Captura ideas, preguntas, tareas, notas rápidas y materiales sin clasificar. Cada nota nueva se crea aquí.

## Procesamiento
1. Elimina lo que ya no sirve.
2. Si requiere un resultado concreto, muévela a `01 Projects`.
3. Si corresponde a una responsabilidad continua, muévela a `02 Áreas`.
4. Si es conocimiento de consulta, muévela a `03 Resources`.
5. Si dejó de estar activa y conviene conservarla, muévela a `04 Archive`.
6. Resume lo importante y enlaza notas relacionadas.
