# MIBibliotecaIA

Tu segundo cerebro para estudio, trabajo y emprendimiento. Está organizado con **PARA** y se apoya en **CODE**: Capturar, Organizar, Destilar y Expresar.

## PARA
- [[00 Inbox/README|00 Inbox]] — captura rápida; revisa y procesa con frecuencia.
- [[01 Projects/README|01 Projects]] — resultados concretos con fecha o condición de cierre.
- [[02 Áreas/README|02 Áreas]] — responsabilidades continuas y estándares que mantener.
- [[03 Resources/README|03 Resources]] — conocimiento y referencias reutilizables.
- [[04 Archive/README|04 Archive]] — proyectos concluidos y material inactivo.
- [[99 Plantillas/README|Plantillas]] — formatos para tus notas.

## Flujo CODE
1. **Capturar:** crea la nota en `00 Inbox`.
2. **Organizar:** decide si corresponde a un proyecto, área, recurso o archivo.
3. **Destilar:** resume lo útil con tus palabras; destaca decisiones, hallazgos y próximos pasos.
4. **Expresar:** convierte notas en entregables: mapas, análisis, informes, clases o publicaciones.
